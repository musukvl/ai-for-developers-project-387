This repository follows the Conventional Commits specification.

Format
- <type>(<scope>): <description>

Types: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert

Keep commit subjects short (under 72 characters) and use the imperative mood.

Example
- feat(frontend): add global brand styles and header accent

Follow this in all new commits and pull request titles
so automated tooling and changelogs remain consistent.
